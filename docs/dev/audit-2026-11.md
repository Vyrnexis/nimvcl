# nimvcl audit (2026-11-20)

Scope: all of `src/` (36.7k lines), read by six auditors; nothing changed yet.
IDs are for tracking the fixes. ✔ = confirmed by a second reading of the code.

## P1 — crashes, data loss, files that cannot be reopened

| ID | Where | Problem | Fix |
|---|---|---|---|
| N1 ✔ | `core/application.nim` (6 guards) | The loop catches `CatchableError` only. An `IndexDefect`/`AssertionDefect` in any handler skips `onException`, escapes `run`, and `shutdown` closes the app (an IDE loses unsaved work without a prompt). | Catch `Exception` at those sites and pass it to `handleError`; a default that logs and continues. |
| N2 ✔ | `dsl/nfm.nim` `ownProps` (pkObject), `Control.free` | Deleting a component leaves `focusControl`/`popupMenu`/`images`/`action`/`menu` of others pointing at it; the save writes the name; the file then fails to load ("not an object of this form"), even non-strict. | The save writes only references to objects that are in the saved tree; optionally clear references on delete. |
| N3 ✔ | `controls/codemodel.nim` `saveFile`, `codeedit.saveToFile` | Truncates the target in place, ignores `writeBuffer` results, marks saved anyway: a full disk leaves a truncated file reported as saved. `saveToFile` also renames the editor and marks saved (no way to save a copy). | Temp file + checked writes + rename, `markSaved` after success; `saveCopyTo(path)`; `saveToFile` goes through `fileName=`. |
| N4 | `controls/codeedit.nim` `loadFromFile` | Name and highlighter change before the read can fail: an unreadable file leaves the old text under the new name; Save then writes it there. | Read first, then rename. |
| N5 | `controls/inspector.nim` `commonProps` | `name` is editable with several targets: all get the same name; the file then fails to load. | Hide `name` for several targets (Delphi does). |
| N6 | `designsurface.nim` `nameUsed` / `uniqueName` | Misses components owned by components (menu items, a Timer under a Panel) and underscore-equal names: duplicate names → file fails to load. | Recurse `components` and `kidsOf`; compare by Nim identifier rules. |
| N7 | `dsl/nfmsyntax.nim`, inspector event rows | Handler or component names `end`, `object`, `inherited`, `true`, `false` (or empty / with spaces) are accepted and written; the file does not parse. | `validNfmName`; reject in the inspector (name and event rows). |
| N8 | `core/application.nim` `runQueued` | A job that opens a modal dialog holds the rest of its batch until the dialog closes (worker results stall behind a message box). | Run one job at a time from the queue (or requeue the rest before each job). |
| N9 | `controls/docking.nim` `loadLayout` | Only invalid JSON is refused. A bad `root`, an unknown version or an exception half way tears the current layout down and leaves a broken one (returns true). A drag in progress is not cancelled. | Validate first (version, shape, known panels), `cancelDrag`, restore the previous layout on failure. |
| N10 | `controls/docking.nim` floats | Floating windows restored at raw saved coordinates: off-screen after a monitor change; on Wayland all saved at 0,0. | Clamp to a display's usable bounds; do not save positions when the origin is unknown. |
| N11 | `controls/menus.nim` `PopupMenu` | No `releaseResources`: a popup menu whose owner is freed stays in `form.popupMenus` (its shortcuts keep firing, action links leak). | Free it with its owner. |

## P2 — correctness

| ID | Where | Problem | Fix |
|---|---|---|---|
| N12 | `nimlexer.skipPragma` | `{.inline}` (closed by a bare `}`) keeps the lexer in pragma state to the next `.}` (verify; Nim accepts it). | Close on `}` too. |
| N13 | `codeedit` markers | Markers on deleted lines jump to the next line; moved lines leave their markers behind; undo does not restore them. | Notify whole-line deletes; shift markers on moves. |
| N14 | `search.replaceAll` | One edit over first..last match: collapsed folds and markers inside are lost, undo keeps the whole span. | Apply edits bottom-up in one undo group. |
| N15 | `folding.nim` indent folds | A column-0 comment or a shallow multi-line string closes the open regions. | Skip comment and string-continuation lines. |
| N16 | `codecommands` Enter | `if x:  # comment` gets no extra indent. | Look at the last code token. |
| N17 | `codemodel` load/save | BOM dropped on save; a lone `\r` line becomes CRLF; deleting/moving the phantom last line changes the trailing newline. | Keep a BOM flag; normalise lone `\r`; keep the trailing newline. |
| N18 | `codeedit` keys | `ssSuper` returns early: Cmd+C/V/Z/A do nothing on macOS; Alt+Backspace ignored. | Map Cmd to the Ctrl commands on macOS. |
| N19 | `types.nim`/`events.nim` | Numpad Enter not mapped: default buttons, Edit, CodeEdit ignore it. | Map `KP_ENTER` to `keyEnter` (and other numpad keys). |
| N20 | `form.nim`, `window.nim` | `constraints` never reach the OS window: the WM shrinks below min, the form fights back (flicker). | `PlatformWindow.setMinSize/setMaxSize` from the constraints. |
| N21 | `form.nim`/`application.nim` close | Closing the main form frees the others without their `onCloseQuery`/`onClose`; `caFree` never fires `onHide`. | Close the other forms first (any veto cancels). |
| N22 | `application.shutdown` | Forms freed in registration order: an open modal's parent window is destroyed first (dangling renderer, low confidence). | Free in reverse order, modal forms first. |
| N23 | `timer.nim` | An enabled Timer of a form closed with `caFree` keeps firing. | Stop the form's timers in `releaseWindow`. |
| N24 | `dsl/props.isDefault`, `parentFont`/`parentColor` nostore | An explicit font/colour equal to the class default under a parent with another value is not saved: the reload inherits the parent's. | Write it when the parent's value differs. |
| N25 | `formmacro.reservedNames` | Component names `icon`, `menu`, `text`, `show`, `close`, `images`… shadow Form members. | Derive the list from Form's props and procs; expose it to the designer. |
| N26 | `formload`/`nfmsyntax.nimExpr` | An enum value named like a component (`center`, `none`) becomes `self.center` in `loadForm`. | Only references for ref-typed properties. |
| N27 | `nfm.convertValue` | Type errors raise even non-strict (whole load fails); a non-Form root stays attached on error; BOM not skipped by the parser. | Warn when non-strict; detach; skip BOM. |
| N28 | `designsurface` | Rubber band mixes controls and tiles; inherited tiles movable; `onDeleted` gets freed controls; placements undo over later inspector edits. | Keep selections homogeneous; respect `inherited`; snapshot before free. |
| N29 | `listview.ListColumns.move` | Moves headers but not the data (cells read by position). | Data index per column, or document as header-only. |
| N30 | `listview` mouse | Right click does not select the item under the pointer (TreeView does). | Select on `mbRight` when not selected. |
| N31 | `grids` | Current cell moves on row/col count change, insert/delete, sort without `onSelectCell`/`onSelectionChanged`. | Fire when the cell changed. |
| N32 | `listview`/`treeview` in-place edit | Editor not clipped to the viewport; not moved after sort. | Clip like the grid; `layoutEdit` after sort. |
| N33 | `spinedit` | `value` ignores typed text until Enter/exit; paste bypasses the digit filter; overflow reverts; app's `onExit` replaces the commit. | Parse on read; filter in the edit; clamp. |
| N34 | `memo` `lines.add` | On a pristine memo `"a\nb"` is one line, later two. | Same path both times. |
| N35 | `listbox`/`combobox` | `items=` / `clear` fire `onChange` and reset scroll; no user-only event. | `onSelect` (user only); keep scroll. |
| N36 | small controls | RadioButton checked before insertion → two checked; `Edit.clear` no-op when readOnly; ComboBox `itemIndex` stale after `items=`; popup stays open when the combo hides. | Each a few lines. |
| N37 | `docking` keys/tabs | Ctrl+F4/Ctrl+Tab act on a panel while focus is elsewhere; many tabs shrink to nothing; zero-size split → NaN weights in the saved layout. | Focus check; min tab width + scroll; guard. |
| N38 | `menus` | Menus taller than the screen have unreachable items; no menu bar overflow; press-drag-release on a bar item does not activate. | Scrollable popup; overflow chevron. |
| N39 | `actions.execute` | `checked` toggled before the handler runs (also when nothing handles it). | Toggle only when handled. |
| N40 | `toolbar` | Disabled button with `image` not dimmed; no overflow. | Alpha when disabled. |
| N41 | `pagecontrol` | `fFirst` not re-clamped after removing a non-active sheet; no wheel scrolling. | `fEnsure` on count change. |
| N42 | `dialogs.executeModal` | Left `running` when the app ends mid-loop. | Reset in `finally`. |
| N43 | `image.nim` | `nextImageId` not atomic (worker threads loading images). | `Atomic`. |
| N44 | `application`/`runOnUi` | Safe only under ORC/ARC, no guard. | Compile-time error otherwise. |

## P3 — performance

| ID | Where | Problem | Fix |
|---|---|---|---|
| Q1 | `memo` word wrap | Every line insert/delete rebuilds the Fenwick tree (O(n)) → appending N lines is O(N²); `fitEnd` copies the line tail per wrap break; no horizontal culling. | Incremental update or one rebuild per batch; offsets instead of slices. |
| Q2 | `memo.text=` | Builds the whole joined text to test emptiness. | Test line count. |
| Q3 | `listview` | Every `items.add` refreshes and relayouts; `fontMetrics` looked up 6-10 times per row per paint. | `beginUpdate`/`endUpdate`; cache the row height. |
| Q4 | `codeedit` paint/keys | Line copies and walks from column 0 per selection edge/match; matches re-run per paint; find status recount per key; `touched` per drag event. | Cache by version; `lent`. |
| Q5 | `actions`/`hint` idle | `updateActions` after every event batch incl. mouse moves; hint does a second hit test per move; PageControl/DockTabs re-measure per move. | Throttle; dirty flags. |
| Q6 | `dsl/props` lookups | `classOf` scans all classes; `findProp` splits names per call; per row/per save. | Tables keyed by type and name. |
| Q7 | `font.nim` | First lookup of a system family runs `fc-list` / scans font folders on the UI thread; `retiredFonts` grows forever. | Scan lazily per family or on a thread; drop retired data when unused. |
| Q8 | undo stacks | Memo/CodeEdit undo capped by count, not bytes; `delete 0` memmove per step. | Byte cap; ring buffer. |
| Q9 | `nfm` inherited save | Ancestor re-read and re-parsed on every save. | Cache by mtime. |

## API gaps (for NimRAD and Delphi parity)

- `Form.onCreate` / `onDestroy`; window state (maximize/minimize/restore, `WindowState`), min/max size, file drop events, display-change events.
- `beginUpdate`/`endUpdate`: ListView, ListBox, Memo (bulk `addStrings` keeping caret/undo), Container layout suspend. (TreeView has it.)
- `Action.shortcuts` (several); `DockSite` panel state event and `loadLayout` error reason, `removePanel`.
- PageControl closable tabs (`closable`, `onTabClose`, middle click); toolbar overflow; status bar panel clicks.
- A public modal helper (`withModal`) that frees the window in `finally`.
- CodeEdit: `saveCopyTo`, `modified=`, colour scheme setter, auto-indent toggle, auto-close pairs, marker identity / numbered bookmarks, completion & hint popup support, BOM flag, multi-line search (or a clear message).
- Designer: undoable property set (with old values), Lock Controls, creation order, `sizeTo`/scale/align to grid, default event per class (`ClassInfo.defaultEvent`), reference scrubbing hook.
- `onKeyDown` `handled` flag; Label `textRole` streamed; `showAccelChar`; `RadioGroup`; Edit/Memo context menu; numpad keys.

## Corrections to the notes taken during the NimRAD audit

- TreeView already has multi-select and `beginUpdate`/`endUpdate`; ListView has a virtual mode (`ownerData`).
- `&&` in captions is a literal `&` everywhere (`common.parseMnemonic`).
- `Application.onException` exists (it misses Defects: N1); `removeIdleHook` exists.
- `FormDesigner.onModified` fires once per committed operation, not per drag step.
- `PageControl` has no `doMouseDown` override; NimRAD's `EditorPages` is fine.
